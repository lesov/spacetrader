# Space Trader

A very small local-only web app MVP for testing a distant-future Solar System trading loop.

## Run Locally

```sh
npm test
npm run serve
```

Then open:

```text
http://localhost:4174
```

## MVP Loop

- Buy low-priced goods at Solar System locations that produce them.
- Use sliders to buy or sell multiple units in one action.
- Spend fuel to travel between planets and major satellites.
- Confirm travel if you try to leave a location before trading there.
- Sell cargo where prices are higher.
- Buy fuel as needed.
- Stay within the ship cargo limit.
