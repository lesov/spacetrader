# Space Trader

A very small local-only web app MVP for testing a space trading loop.

## Run Locally

```sh
npm test
npm run serve
```

Then open:

```text
http://localhost:4173
```

## MVP Loop

- Buy low-priced goods on planets that produce them.
- Spend fuel to travel between planets.
- Sell cargo where prices are higher.
- Buy fuel as needed.
- Stay within the ship cargo limit.
